# Agentnexos

**Where agents connect. / حيث تتصل أنظمة الوكلاء بالعمل الحقيقي.**

منصة عربية أولًا لبناء وتشغيل أنظمة وكلاء مخصصة للمؤسسات في مصر والخليج والشرق الأوسط، بصلاحيات محددة وموافقات بشرية وسجل نتيجة قابل للمراجعة.

## الحالة الحالية

- [تسليم الدورة — 1 أكتوبر 2026](./docs/UPGRADE-HANDOFF-2026-10-01.md) — المنجز وأدلة النشر وحدود التشغيل والمراحل التالية ومعايير قبولها.

- المرجع الحالي: [الخطة الشاملة](./docs/COMPREHENSIVE-UPGRADE-2026-09-30.md) و[سجل دورة الترقيات](./docs/UPGRADE-RELEASE-STATUS-2026-09-30.md). تقارير 29 سبتمبر والتحديث03 سجلات تاريخية؛ حالة كل إصدار موثقة منفصلًا.
- القالب وصوره وخطوطه وألوانه وترتيبه محفوظة. مساحة الوكيل داكنة؛ رحلة /start محلية لإعداد موجز مشروع بلا إرسال أو حفظ خادم، وصفحة /about تشرح المنهج.
- Next16.3.7، وAI SDK7 وMastra1.72 مثبتة بالـlockfile. تحقق الإصدار النهائي يميز المعاينة عن الإنتاج والتشغيل الحي.
- واجهة دردشة عربية/إنجليزية؛ AI SDK 7 وMastra 1.72 لمحرك تصميم عمليات للقراءة فقط، منفصل عن APIs المؤسسة المقفولة. تحقق النشر والنماذج الحية مسجل في تقرير الدفعة؛ البناء وحده لا يثبت التشغيل.
- جدول حدود استخدام Supabase مطبق في المشروع الذي حدده المالك؛ ليس قاعدة بيانات مؤسسات أو ذاكرة محادثات.
- عائق التشغيل الحي بتاريخ 30 سبتمبر: سجل Supabase يؤكد رد `401` على طلب الجاهزية من Vercel للمشروع الصحيح. يلزم ضبط `AGENTNEXOS_SUPABASE_SECRET_KEY` في Vercel Production بمفتاح خادم المشروع الصحيح؛ لا ترسل قيمته في الدردشة. النماذج الحية لم تُختبر بعد، ولا يوجد رد وهمي بديل.
- الهوية والمؤسسات والموافقات الدائمة وCRM والبريد وERP وتنفيذ الكود والبحث العام والذاكرة طويلة الأجل **غير متاحة** في هذه التجربة.
- الأيقونات الحالية عامة من القالب؛ هوية Agentnexos الأصلية ضمن المرحلة 3 بعد اختيار المالك.

## التشغيل المحلي

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## بوابات التحقق

```bash
pnpm audit --prod
pnpm typecheck
pnpm i18n:check
pnpm test:agentnexos
pnpm lint
pnpm build
```

بوابة المتصفح: ثبّت Chromium بـ`pnpm exec playwright install chromium`، ثم شغّل البناء بـ`pnpm start` ونفّذ `pnpm verify:site http://localhost:3000`. [دليل الإصدار](./docs/RELEASE-VERIFICATION.md) يوضح الفحوص وما لا تثبته.

ESLint يعمل؛ التحذيرات المتبقية مسجلة في تقرير الدفعة. اختبارات المزود الوهمية لا تثبت نجاح Groq الإنتاجي.

## متغيرات البيئة المخطط لها

لا تُحفظ القيم في Git أو الوثائق.

| المتغير | الاستخدام |
|---|---|
| `GROQ_API_KEY` | وكيل تحليل العملية — Qwen |
| `GROQ_API_KEY1` | وكيل التخطيط/الأدوات — Qwen |
| `GROQ_API_KEY2` | المراجع — GPT-OSS |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط Supabase العام عند إنشائه |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | مفتاح العميل العام |
| `SUPABASE_SECRET_KEY` | خادم فقط؛ ممنوع في العميل |
| `NEXT_PUBLIC_SITE_URL` | الرابط الأساسي |

أبلغ المالك أن مفاتيح Groq الثلاثة موجودة في Vercel Production؛ ما زال يلزم فحص وجود وصلاحية بلا كشف القيم.
