# AgentNexos

**Connecting knowledge to decisions, and decisions to action. / نربط المعرفة بالقرار، والقرار بالتنفيذ.**

منصة عربية أولًا لبناء وتشغيل أنظمة وكلاء مخصصة للمؤسسات في مصر والخليج والشرق الأوسط، بصلاحيات محددة وموافقات بشرية وسجل نتيجة قابل للمراجعة.

## الحالة الحالية

المرجع الحالي: [تسليم إعادة التصميم — 1 أكتوبر 2026](./docs/REDESIGN-HANDOFF-2026-10-01.md) و[الخطة الشاملة](./docs/COMPREHENSIVE-REDESIGN-2026-10-01.md). التفويض اللاحق من المالك استبدل القالب القديم بتصميم أسود مطفي وأخضر هادئ؛ قواعد حفظ الصور القديمة أصبحت تاريخية لهذا النطاق.

المصدر المنفذ: موقع عام عربي/إنجليزي، 8 حلول و12 قطاعًا و3 مقالات مكتملة، منهج تقني وخدمات وجدوى وموجز مشروع محلي. مساحة الوكيل والحساب تتطلبان هوية Supabase مؤكدة؛ المحادثات معزولة ومخزنة تحت الحساب، مع حذف مؤكد وتعديل الاسم واستعادة كلمة المرور. المصدر يستخدم Next.js16.3.7 وVercel AI SDK7 وMastra1.72 بالاعتمادات الموجودة.

**نشر هذا المصدر للإنتاج ما زال متوقفًا على إعداد المصادقة والتحقق من حساب حقيقي.** توجد PRs ومعاينات مستقلة؛ قاعدة البيانات أضيفت إليها الجداول وسياسات العزل واختُبرت دون ترك بيانات الاختبار. الإنتاج السابق لم يُستبدل بإصدار يعطل الدخول. تفاصيل SHA وحالة كل مرحلة في التسليم، وليس البناء دليلًا على التشغيل الحي.

RAG/GraphRAG مؤسسي، MCP/A2A، تنفيذ مستمر وموافقات طويلة المدى، sandbox وCRM والبريد وERP أطر تطوير مستقبلية وليست قدرات مفعلة في التجربة. النص التجاري يميز نطاق المشروع المقترح عن مساحة التصميم الحالية.

## التشغيل المحلي

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## بوابات التحقق

```bash
pnpm audit --prod
pnpm typecheck
pnpm i18n:check
pnpm test:agentnexos
pnpm lint
pnpm build --webpack
```

بوابة المتصفح: ثبّت Chromium بـ`pnpm exec playwright install chromium`، ثم شغّل البناء بـ`pnpm start` ونفّذ `pnpm verify:site http://localhost:3000`. [دليل الإصدار](./docs/RELEASE-VERIFICATION.md) يوضح الفحوص وما لا تثبته.

ESLint يعمل؛ التحذيرات المتبقية مسجلة في تقرير الدفعة. اختبارات المزود الوهمية لا تثبت نجاح Groq الإنتاجي.

## متغيرات البيئة

لا تُحفظ القيم في Git أو الوثائق.

| المتغير | الاستخدام |
|---|---|
| `GROQ_API_KEY` | وكيل تحليل العملية — Qwen |
| `GROQ_API_KEY1` | وكيل التخطيط/الأدوات — Qwen |
| `GROQ_API_KEY2` | المراجع — GPT-OSS |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط Supabase العام عند إنشائه |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | مفتاح العميل العام |
| `SUPABASE_SECRET_KEY` | خادم فقط؛ ممنوع في العميل |
| `NEXT_PUBLIC_SITE_URL` | الرابط الأساسي |

أبلغ المالك أن مفاتيح Groq الثلاثة موجودة في Vercel Production؛ ما زال يلزم فحص وجود وصلاحية بلا كشف القيم.
