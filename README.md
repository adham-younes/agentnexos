# AGYNEXA

**AI designed around the way you work. / نصمّم الذكاء حول طريقة عملك.**

نصمّم أنظمة وكلاء ذكاء اصطناعي للمؤسسات والشركات حول العالم. الموقع بالإنجليزية افتراضيًا مع تبديل عربي، والمساعد العام يقدم تحليلًا وتصميمًا دون تنفيذ داخل أنظمة العملاء. حفظ المحادثات اختياري ومعزول حسب الحساب.

## التشغيل المحلي

```bash
pnpm install --frozen-lockfile
pnpm dev
```

## بوابة التحقق الإنتاجي

وفق قرار المالك: لا اختبارات أو lint/typecheck أو builds محلية أو على Preview لهذه الحزمة. بعد النشر الإنتاجي المأذون يُسجل SHA المنشور وتُشغّل جولة واحدة محددة النطاق:

```bash
pnpm verify:production --commit <released-40-character-sha>
```

السكربت يستهدف `https://agynexa.si` فقط، ويحفظ نتيجة المسارات والتصميم واللغة والموارد في `output/premium-platform/`. تضاف نتائج الحسابات والعزل والنماذج الحية إلى دليل الإصدار نفسه؛ نجاح عرض الموقع لا يثبت تلك المسارات. لا إعادة لفحص ناجح دون تغيير مؤثر، ولا بريد أو بيانات عملاء ضمن الاختبارات.

## متغيرات البيئة المخطط لها

لا تُحفظ القيم في Git أو الوثائق.

| المتغير | الاستخدام |
|---|---|
| `GROQ_API_KEY` | وكيل تحليل العملية — Qwen |
| `GROQ_API_KEY1` | وكيل التخطيط/الأدوات — Qwen |
| `GROQ_API_KEY2` | المراجع — GPT-OSS |
| `NEXT_PUBLIC_SUPABASE_URL` | رابط Supabase العام عند إنشائه |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | مفتاح العميل العام |
| `SUPABASE_SECRET_KEY` | خادم فقط؛ ممنوع في العميل |
| `NEXT_PUBLIC_SITE_URL` | الرابط الأساسي |

أبلغ المالك أن مفاتيح Groq الثلاثة موجودة في Vercel Production؛ ما زال يلزم فحص وجود وصلاحية بلا كشف القيم.
