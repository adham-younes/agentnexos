خط الأساس: الإنتاج d85623907d9c63ee3ba193bc22a72e121c8ee88c، بعد فحص 66 حالة ورحلة موجز عربية/إنجليزية. النطاق المخطط: قائمة الهاتف والكيبورد وتقليل الحركة، تحميل الصور مع الحفاظ على أصول القالب، تحقق آلي لجميع الصفحات والرحلات، توثيق الإصدار.

## التنفيذ

- القائمة المغلقة inert؛ المفتوحة تضبط التركيز وتغلق بالكيبورد أو المؤشر وتعيد التركيز وتوقف تفاعل الخلفية. دعم الانتقال إلى سطح المكتب والارتفاع القصير دون قطع عناصر القائمة. الملاحة تبقى أعلى القائمة ويظل زر الإغلاق ظاهرًا.
- فصل main والملاحة والتذييل دلاليًا مع الحفاظ على نفس ترتيب الأقسام وحاوية القالب. رابط تخطي المحتوى وثبات هدفه على جميع الصفحات. بطاقات الأمن تدعم الكيبورد وحالة الاختيار.
- تفضيل تقليل الحركة يتابع تغييره مباشرة: الفيديو يتوقف، الرسوم ترسم إطارًا ثابتًا، دوران الكلمات/المناطق يتوقف، وتأثيرات CSS تتوقف دون ترك النص مخفيًا. الحركة الأصلية تبقى عند عدم اختيار التفضيل.
- تثبيت أبعاد الصور الأصلية من الصفحة المنشورة؛ لا تغيير source أو ملفات الأصل. صور الأقسام اللاحقة تؤجل التحميل وتفك الترميز خارج مسار الرسم. لا ندعي Lighthouse أو LCP محسنًا دون قياس منفصل.
- إضافة Playwright 1.63.0 للاختبار فقط وتثبيته في lockfile؛ لا ترقية رئيسية لحزم التطبيق. CI يستخدم نفس pnpm 11.19.0 المفحوص محليًا، مع بناء وفحص موقع محفوظ كartifact. لا تغيير فوترة أو حماية الفروع.
- pnpm verify:site يفحص 66 حالة، HTTP، overflow، الصور الظاهرة، لغة/اتجاه/landmarks/canonical/روابط/الأصول، ثم قائمة قصيرة وتركيز وEscape وتقليل حركة وموجز/تنزيل/مسح. يفحص جاهزية الخدمة دون استدعاء نموذج حي ويبقي legacy APIs مغلقة. الحالة العامة غير الجاهزة تسجل صراحةً.

## نتائج الفحص وملاحظات البيئة

أثناء تعديل اعتماد الاختبار، جلسة Next dev القديمة احتفظت بوحدات cache غير صالحة وأظهرت أخطاء Turbopack. لم تُعدّ تلك الجولة نجاحًا؛ أوقفت الجلسة والبناء السابق وأعدت بناء نسخة إنتاجية وفحصها. فحص الصور كشف أن lazy loading دون أبعاد قد يسبب فراغات وتغير layout؛ ثُبتت الأبعاد الأصلية وأضيف تحقق مصدر/ترتيب/أبعاد الأصول.

الفحوص وروابط المعاينة والإنتاج النهائية تُسجل بعد اكتمالها. لا يدّعي هذا الإصدار تشغيل Groq حيًا أو durable execution أو sandbox أو شهادة إتاحة كاملة.
