## 2. البنية البرمجية والمكونات المنفذة

### 2.1 صفحة الحلول التخصصية (`app/[locale]/solutions/page.tsx`)
- تستعرض بالتفصيل المعماري 3 سيناريوهات حقيقية للشركات في الشرق الأوسط:
  - **الفوترة الإلكترونية ZATCA (المرحلة الثانية):** فحص XML، توليد التوقيع الرقمي والتشفير، وإرسال الفواتير لمنصة فاتورة مع مسار مراجعة بشري عند الرفض.
  - **حوكمة المشتريات وجداول الصلاحيات DOA:** مطابقة أوامر الشراء الثلاثية (Three-Way Match) وفحص الميزانيات واعتماد أوامر التوريد طبقاً لمصفوفة الصلاحيات المعتمدة.
  - **تنسيق العمليات بين الأنظمة المؤسسية (Cross-System Orchestration):** استرجاع وتحديث البيانات بين ERP وCRM والبريد مع ضمان الحتمية والتحقق من الهوية.
- تصميم متوافق مع نظام القالب، واستخدام تدرجات بصرية وألوان متناسقة، ودعوة للعمل (CTA) تقود مباشرة إلى تشغيل بيئة الوكلاء `/agentnexos`.

### 2.2 صفحة الأمان وحوكمة البيانات (`app/[locale]/security/page.tsx`)
- تعرض الركائز الست للأمان المؤسسي في بطاقات تفاعلية مع تفاصيل المعايير التقنية:
  1. عزل المستأجرين المتعددين وسياسات مستوى الصف (RLS).
  2. سجل التدقيق المشفر غير القابل للتلاعب (HMAC SHA-256).
  3. بوابات الاعتماد البشري الإلزامي (Human-in-the-Loop).
  4. درع حماية النماذج من الاختراق والحقن (Multi-Vector Prompt Guard).
  5. التجهيل الفوري للبيانات الحساسة والأسرار (PII & Secret Redaction).
  6. الحصص التشغيلية وحدود التدفق الساعية (Multi-Tenant Rate Limiting).

### 2.3 صفحات سياسة الخصوصية والشروط (`app/[locale]/privacy/page.tsx` و `app/[locale]/terms/page.tsx`)
- صياغة مهنية تضمن التزام منصة Agentnexos بحماية بيانات العملاء والمؤسسات.
- بنود واضحة وصريحة تؤكد أن بيانات المؤسسات لا تُستخدم مطلقاً لأي تدريب لنماذج عامة.
- توضيح معايير التشفير أثناء النقل والتخزين، وحقوق حذف البيانات، وشروط التوافق ومسؤوليات التشغيل.

### 2.4 محرك تحسين محركات البحث والخرائط الديناميكية (`app/sitemap.ts` و `app/robots.ts`)
- `sitemap.ts`: يُرجع مصفوفة ديناميكية من الروابط المتعددة لكل من:
  - `/ar` و `/en`
  - `/ar/agentnexos` و `/en/agentnexos`
  - `/ar/solutions` و `/en/solutions`
  - `/ar/security` و `/en/security`
  - `/ar/privacy` و `/en/privacy`
  - `/ar/terms` و `/en/terms`
- ربط لغوي دقيق عبر `alternates.languages` لتحديد الصفحة المقابلة في كل لغة لمحركات البحث (hreflang).
- `robots.ts`: توجيه محركات البحث لفهرسة الصفحات العامة ومنع فحص مسارات `/api/*` لضمان حماية الموارد وسرية نقاط النهاية البرمجية.
