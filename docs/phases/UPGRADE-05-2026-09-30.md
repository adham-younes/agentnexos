# ترقية 05 — رحلة مشروع واضحة ومحتوى قابل للتحقق

خط الأساس: الإنتاج b047973ba7fcf16b763bdbff7df130be40a3c221، بعد تحقق 54 حالة على الرابط الرسمي. النطاق المخطط: رحلة تجارية حقيقية مع الحفاظ على تركيب القالب وصوره وألوانه، وضوح القدرات بالعربي والإنجليزي، موجز عملية محلي، منهج عمل وصفحات وصفية دقيقة.

## التغييرات

- أزرار بدء المشروع في الملاحة وقسم الدعوة والتكاملات ومنهج التسليم والتذييل تفتح /start بدل الدوران بين أقسام الصفحة. صفحات المنتج توفر مسار المشروع ومساحة الوكيل كخيارين واضحين.
- نموذج موجز محلي للهدف والمالك وبداية العملية ومصدر الحقيقة والمخرج والقبول والفشل وأعلى صلاحية. يتحقق برمجيًا من الحقول والحجم/الوقت؛ يحدد الحاجة إلى الاعتماد وحساسية الأفعال دون منح أي صلاحية. التنزيل Markdown اختياري؛ لا قاعدة بيانات أو إرسال فريق أو اتصال نموذج.
- الحساب يصف حجم العمل الحالي فقط، ولا يدعي وقتًا موفرًا أو ROI. نص المستخدم مقتبس في التصدير وتحيّد وسوم HTML.
- صفحة /about تشرح الاكتشاف والتجربة والأدلة والتوسع، دون شهادات أو أسماء عملاء. إزالة شهادات العملاء الخيالية المخفية نهائيًا؛ قسم معايير النجاح الحالي يحتفظ بنفس التركيب.
- إصلاح الوعد الإنجليزي القديم No supervision required، وحدود التكاملات، والإفصاح عن معالجة موجز المشروع. إضافة مسارات sitemap ووصف المشاركة الصحيح لمساحة الوكيل والصفحات الجديدة وصفحات المنتج.
- صور وخطوط وألوان وترتيب أقسام الصفحة الرئيسية محفوظة؛ لم نرقّ dependencies أو نفتح endpoints مؤسسية أو نغير حسابات الفوترة.

## التحقق والنشر

النتائج الفعلية وروابط النشر تضاف بعد اكتمال الفحوص. معيار النشر: typecheck/i18n/tests/lint/build، صفحات AR/EN عند 390/768/1440، رحلة موجز ناقص/مكتمل/حساس/تنزيل/مسح دون إرسال بيانات النموذج، Preview READY ثم دمج عادي ثم Production READY والتحقق من الرابط الرسمي. GitHub Actions معطل بسبب قفل فوترة الحساب؛ لا يُدّعى نجاحه ولا تُتجاوز حماية المستودع.
