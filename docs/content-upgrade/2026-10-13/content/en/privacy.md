# Public experience privacy and data handling

This notice describes the current public experience. Enterprise projects need their own provider, purpose, access, retention and responsible-contact arrangements.

## The brief prepared in your browser

Project-form answers remain in page memory and are not sent to a team or server to prepare the brief. Download and review the file before sharing it. Closing the page or clearing fields removes local state.

## What happens when you send an assistant message

Your request and the relevant conversation context go to a Vercel server and then Groq models for processing. Under the current experience’s stated behavior, conversation state lives in tab memory and is not stored in the application database. Use fictional data; do not enter secrets, customer data or credentials.

## Hosting and technical usage data

Vercel hosts the site and may process connection data needed to deliver it. Vercel Analytics is included, so a local brief does not imply an absence of technical usage data.

The current implementation is described as recording an HMAC fingerprint of the connection address, request time and status, model roles, token usage, tool-policy decisions and stage timing in Supabase. It excludes prompt, response and reference content and supports abuse prevention.

Records older than 48 hours are cleaned when a new request is reserved. There is currently no scheduled deletion guaranteeing a maximum retention deadline.

## Providers and external references

Groq processing and retention depend on the plan, settings and contract. This notice does not promise universal no-training or no-retention. Technical reference retrieval connects to selected official sites under the current tool scope.

## Before using real data

The project specifies data, purpose, providers, processing locations, retention, deletion and privacy-request channels. There is no general in-country residency guarantee. Responsible-party details and contact channels must be confirmed before customer data is accepted.
