# Prepare a brief for the project you want to test

Describe the task, sources, decision owner and success criteria. The form collects your answers in a local file for team review; it does not submit an enquiry or connect company systems.

## Your answers stay on this page

Preparation, review and download happen in your browser without an AI call. Closing the tab loses local state, so download a copy before leaving. The privacy notice covers technical usage data.

## Start with an example, then adapt the task

The fictional example describes purchase-review preparation. It contains no real company data or approval policy ready for use. Review each field; clear the form before loading the example again.

[First workflow guide](/en/resources/first-workflow)

## Form fields

### What is the task and where does it stall?

Describe a recurring request and what takes team time.

### Who owns the process and approves the result?

Use roles, such as purchasing owner. Personal names are unnecessary.

### What triggers the task?

For example, a request, question or follow-up date.

### What are the approved sources?

Describe record types, owners and updates without pasting real data.

### What output is required?

Specify what the reviewer receives: comparison, gaps or draft.

### How will you accept or reject the result?

Define a check the team can perform, rather than “a great answer.”

### When should the task stop and who receives it?

Describe gaps, conflicts, outages and checks before retrying.

### Highest permission the task needs

This describes a project requirement; it does not grant access.

### Cases per month

Optional. Enter a non-negative whole number.

### Average working minutes per case

Optional. This is a workload baseline, not expected savings.

## Permission options

- Read only
- Prepare drafts
- Send or update an external system
- Financial action
- Delete data

## Interface and state copy

- `load_example`: Use the fictional example
- `clear`: Clear fields
- `required`: Complete this field to prepare the brief.
- `invalid_number`: Enter a non-negative whole number.
- `review_heading`: Review the brief before downloading
- `review_body`: This is a complete preview of your answers. Review scope, ownership, sources and acceptance.
- `approval_note`: The proposed scope includes an action requiring authorization and human review. Listing it here does not enable it.
- `baseline`: Baseline: {minutes} working minutes per month. Not estimated savings.
- `edit`: Edit answers
- `download_md`: Download Markdown
- `print`: Print the brief or save as PDF
- `local_note`: This brief has not been sent to a team or system.
- `success`: Download started. Review the file before sharing.
- `download_error`: Could not prepare the download. Review the preview and try again.
