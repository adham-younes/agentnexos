# Guides for preparing your first project

Practical material for selecting a task, identifying sources and defining acceptance. Use it with process owners and technical teams before connecting real data.

## Choose your first workflow

Compare tasks by recurrence, delay costs, data quality and reviewability. The guide provides selection questions and a scope template for the project brief.

[First workflow guide](/en/resources/first-workflow)

## Test the system before operation

Build cases for correct outcomes, missing data, conflicting sources, denied access and connection failures. Define expected results before viewing the answer.

[Acceptance testing guide](/en/resources/acceptance-testing)

## Use a guide with an example from your work

Reading helps organize the question; demonstrating capability needs a scoped trial. Start with a fictional description, identify the human decision and use the local brief to collect requirements.
