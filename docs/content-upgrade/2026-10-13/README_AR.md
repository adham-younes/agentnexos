# Agentnexos — حزمة ترقية المحتوى

تاريخ الإعداد: 13 أكتوبر 2026. اللغة الأساسية العربية، مع نسخة إنجليزية مقابلة كاملة. الحزمة تتضمن 21 مسارًا لكل لغة، أي 42 صفحة محلية؛ 88 قسمًا لكل لغة، إلى جانب الأسئلة ونصوص الموجز والمساعد والحالات ومخرجات توضيحية لأربع حلول.

## ما تستلمه

| الملف | الاستخدام |
| --- | --- |
| `content/site_content.json` | المصدر المنظم للمحتوى والروابط ونصوص التفاعل باللغتين |
| `content/ar/` و`content/en/` | ملف Markdown كامل لكل صفحة |
| `Agentnexos_Content_AR.md` و`Agentnexos_Content_EN.md` | كتابا المحتوى كاملين للقراءة والبحث |
| `Agentnexos_Content_Review.html` | مراجعة المحتوى على الهاتف والمتصفح مع فهرس ونسخة إنجليزية لكل صفحة |
| `Agentnexos_Content_AR.pdf` | نسخة عربية كاملة قابلة للقراءة على الهاتف |
| `CODEX_IMPLEMENTATION_GUIDE_AR.md` | التعليمات المنفصلة لمطور الترقية |
| `route_manifest.json` | خريطة المسارات والتحويلات وحالات النشر |
| `runtime_config.example.json` | إعدادات مقترحة مع تعطيل الوظائف غير المتصلة |
| `EDITORIAL_EVIDENCE_AND_QA_AR.md` | المرجعية والادعاءات ومراجعة المحتوى |
| `content_validation.json` | نتيجة تحقق المسارات والتكافؤ البنيوي والروابط |

## قرارات إعادة الهيكلة

تتحول المنصة العامة إلى عرض واضح لخدمات هندسة أنظمة وكلاء مخصصة. تبقى التجربة الحالية منفصلة ومعرّفة كمساعد تصميم وموجز محلي. تحل الخدمات محل صفحة المنصة، والحوكمة محل الأمان، مع تحويلات تحفظ الروابط القديمة. تصبح الحلول أربع صفحات تفصيلية، والقطاعات ثلاثة سياقات أعمال مستقلة. يضاف منهج تنفيذ ودليل اختيار المهمة ودليل اختبار القبول. لا يُنشر قسم عملاء أو نتائج أو أسعار أو شهادات مخترعة.

لم يتم نشر هذه الحزمة أو تعديل الموقع أو الوصول إلى المستودع في هذه الخطوة. ملفات القراءة ليست تصميمًا نهائيًا للتطبيق. الصفحات القانونية تحتوي نصوصًا كاملة لكنها تحتاج مطابقة بيانات مقدم الخدمة والموردين والسلوك الفعلي قبل استبدال النصوص المنشورة. شرح ذلك في دليل Codex، دون ترك حقول ناقصة في الواجهة.

## كيف تسلمها إلى Codex

أرفق ملف ZIP كاملًا، وأرفق `CODEX_IMPLEMENTATION_GUIDE_AR.md` مستقلًا، واطلب تنفيذ الترقية في مستودع Agentnexos بعد قراءة تعليماته. الحزمة تحدد النصوص والمسارات والقرارات؛ على Codex قراءة كود المشروع وتحديد مواضع الدمج ثم إظهار المعاينة والتحقق.

النص المقترح لبدء جلسة التنفيذ:

> نفّذ ترقية محتوى Agentnexos باستخدام الحزمة المرفقة. اقرأ CODEX_IMPLEMENTATION_GUIDE_AR.md أولًا ثم route_manifest.json وcontent/site_content.json. طبق الصفحات العربية والإنجليزية كاملة، والمسارات الجديدة والتحويلات والتنقل، وحسّن معاينة الموجز والطباعة والنصوص التفاعلية وفق المواصفات. افحص الكود والقدرات قبل تغيير أي إفصاح، واحفظ الصفحات القانونية القائمة حتى تحسم شروط نشر البديل. لا تختصر المحتوى إلى شعارات، ولا تضف شهادات أو نتائج أو وظائف لم تُنفذ. أنجز المعاينة وفحوص المشروع وارجع بأدلة التحقق وما يحتاج حسمًا للنشر.

ملف `runtime_config.example.json` لا يحتوي أسرارًا ولا مفاتيح API، ولا يفوض أدوات التنفيذ. حد الطلبات والحروف يجب أن يطابق الخادم في مرحلة الدمج.
