# Practical tools to scope the project and test its results

Use these templates to prepare a discussion between the process owner and technical team. They identify decisions needed before development and ways to evaluate outputs beyond a general impression of an answer.

## Define the first process

The workflow brief records the trigger, inputs, knowledge source, owner, output, and incomplete-input path. It asks for a baseline when available so performance comparisons use actual information.

[Download the workflow brief](/downloads/agentnexos/workflow-brief-en.md)

## Acceptance test plan

The plan covers ordinary cases, incomplete requests, conflicting sources, missing permissions, changed approval inputs, and lost tool responses. Each case has an expected result and observable evidence.

[Download the acceptance test plan](/downloads/agentnexos/acceptance-plan-en.md)

## Read the results

Retrieval tests review source, version, and relevance. Tool tests review inputs, policy, and effects. Process tests combine them and measure completion and exceptions that needed intervention.

Review time, corrections, completed cases, and operating cost can be measured. These measures do not automatically establish cash savings; identify what actually changed in team time or work cost.
