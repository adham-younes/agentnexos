# النموذج المرجعي

نموذج React منفصل يعرض النصوص الكاملة لجميع21 صفحة بلغتين. يبدأ الرابط بـ`#/ar/` أو`#/en/` ويحتفظ بتغيير اللغة على المسار نفسه. هذه روابط معاينة، لاroutes إنتاج Next.

```bash
npm ci
npm run typecheck
npm run build
node render-check.mjs
python verify-reference.py
npm run serve
```

يخدم static server النموذج على منفذ4173 في بيئة Codex المحلية. افحصه عبر المتصفح المتاح لتلك البيئة أو معاينة HTTPS مصرح بها. لا تستخدم نفقًا لتجاوز سياسة تمنع ملفات محلية في متصفح سحابي.

`Agentnexos_Experience_Review.html` في جذر الحزمة يضم JavaScript وCSS وصور الواجهة؛ تظل الخطوط منGoogle Fonts، والفيديو في مجلد assets المجاور. للحصول على خطوط المنتج في الإنتاج احتفظ بمحمل `next/font` الحالي.

أزرار المساعد تختبر إدخال مثال وعرض حالات التصميم، ولا تتصل بمزود ولا تنتج ردًا. نموذج الموجز يحتفظ بالإجابات في ذاكرة الصفحة، ويراجعها وينزل Markdown محليًا. انقل واجهة المحادثة من الكود الحي الحالي؛ لا تنقل المحاكاة إلى الإنتاج.

مكونات Button وSidebar وTable وتبعيات Sidebar من نسخة المستودع المفحوصة، مع أنماط المرجع. لا تنقل package.json أوملف القفل إلى التطبيق. تثبيت تبعيات المعاينة لا يعني الحاجة إلى ترقية تبعيات الإنتاج.
