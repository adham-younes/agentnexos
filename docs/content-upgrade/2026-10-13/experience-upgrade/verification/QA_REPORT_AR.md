# نتائج التحقق وحدودها

## ما اجتاز الفحص

- `npm run typecheck` للنموذج المستقل: نجاح.
- `npm run build`: نجاح، React production bundle وCSS.
- React server render:42 صفحة/لغة، مع834 مقارنة نصية للعناوين والفقرات والقوائم والروابط وFAQ والمخرجات والحقول. لا توجد نصوص مفقودة أو روابط نموذج لمسار مجهول.
- نسخة المحتوى داخل النموذج مطابقة بالبايت لحزمة المحتوى الأصلية؛ SHA في تقريرJSON.
- الصور السبع ملفاتWebP فعلية ويمكن فكها، مع أبعاد ثابتة.
- الفيديو1280×716، مدته5.04 ثانية تقريبًا، حجمه1,030,996 بايت، ومسار صوت غير موجود.
- تباين الأزواج الأساسية: النص17.10، النص الثانوي8.74، زر الأخضر/الأسود8.03، الخطأ9.68، حد التحكم4.13. الحساب لألوان معتمة ثابتة، ولا يغطي كل حالة من مكتباتUI.

## فحوص لم تُنفذ

الفحص التفاعلي بعد الترقية في المتصفح لم يُنفذ. المتصفح السحابي يمنع فتح `file://`، ولم يُنشأ نفق أو يُتجاوز المنع. لذلك لا توجد لقطات عربية/إنجليزية للنتيجة عند390/768/1440، ولا دليل على تحميل الخطوط أو غيابoverflow في المتصفح. البناء وserver render لا يعوضان هذا الفحص.

لم تُشغّل تقييمات النموذج24حالة على مزود حي، ولم يُستبدل prompt الإنتاجي. لم تُنفذ typecheck/build/tests للتطبيق الكامل لأن هذه الجولة تضيف حزمة جانبية، لا تعديلات تطبيق. لم تُنشر أي مرحلة على إنتاجAgentnexos.

الفحص الإنتاجي الحالي كان للرئيسية ومساحة الوكيل: ظهر وضع جاهزية القراءة والتخطيط وحد1000طلب/24ساعة. لم يُرسل طلب للنموذج؛ هذا ليس اختبار رد أو حفظ أو أداء مزود.

لا تعد هذه النتائج شهادة وصول أو قياسCore Web Vitals أو ضمان أمن. الفحوص المعلقة موضحة في خطة الإصدارات، وتمنع إعلان ترقية الواجهات كإنتاج مكتمل.

## إعادة الفحص

داخل `prototype`: تثبيت مقفل عبر `npm ci`، ثم `npm run typecheck`، ثم `npm run build`، ثم `node render-check.mjs`، ثم `python verify-reference.py`. يتطلب فحص الأصول Python معPillow وffprobe. النصوص المولدة للاختبار artifacts وليست صفحاتNext أولقطاتمتصفح.

الملفات: `content-and-assets-check.json` و`source-inventory.json` و`before-home-ar.jpg`. ملفZIP الخاص بHTMLالمولد يوفر مادة مقارنة42نسخة؛ لا يثبت هندسة العرض في Chrome.
