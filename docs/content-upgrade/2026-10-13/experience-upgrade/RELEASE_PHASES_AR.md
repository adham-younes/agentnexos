# خطة إصدارات مستقلة إلى الإنتاج

هذه خطة تنفيذ لاحقة، وليست سجل نشر من هذه الجولة. طلب المالك يجيز متابعة المراحل تباعًا؛ تنتهي كل مرحلة بدليل إنتاج مستقل قبل بدء التالية. لا يوجد دمج مباشر إلى main، أو `--admin`، أو تجاوز حماية، أو تغيير فوترة/أسرار ضمن النطاق.

## بروتوكول كل مرحلة

1. اقرأ AGENTS والأدلة الأحدث، افحص `git status` ورأس main وPRs ذات الصلة. لا تكتب فوق عمل سابق. جهّز branch من آخر main المقبول.
2. اكتب نطاق المرحلة ومعايير القبول ومسارات التغيير وخطة التراجع في `docs/phases/EXPERIENCE-0N-2026-10-13.md` قبل التعديل.
3. نفذ أقل تغيير يحقق المرحلة. استخدم نسخة المحتوى المعتمدة ومكونات المستودع؛ لا تغير مزودات أو أسرار أو قاعدة بيانات لتسهيل عرض.
4. شغّل `pnpm typecheck` و`pnpm i18n:check` و`pnpm build` و`pnpm lint` والاختبارات المرتبطة. أبلغ عن التحذيرات الحالية دون اختراع عدد baseline. عند تغيير الوكيل شغّل `pnpm test:agentnexos`. لا تفترض نجاح CI إذا كانت الفوترة تمنع بدء خطواته.
5. أنشئ PR ومعاينة Vercel، ثم افحص المسارات والحالات المتغيرة عند390 و768 و1440 لكل لغة. الصور المكتبية لا تثبت الهاتف. قارن المحتوى المعروض بالقالب المعتمد، وراجع fonts/overflow/focus/reduced-motion وأخطاء المتصفح.
6. ادمج بالطريق العادي بعد استيفاء البوابات. إن منعت الحماية الدمج، سجّل السبب؛ لا تعالج المنع بإضعاف الحماية. طلب المالك الحالي يكفي للاستمرار داخل هذا النطاق، فلا توقف العمل لطلب موافقات متكررة.
7. انتظر Deployment الإنتاج من main بحالة READY وبـSHA مطابق. افتح الرابط الرسمي، اختبر `/ar` و`/en` ورحلة المرحلة. Preview أو build المحلي لا يثبت الإنتاج.
8. سجّل SHA وPR وDeployment URL ومعرفه ووقت التحقق ونتائج الاختبارات وأسماء اللقطات. توقف إذا أخفق الإنتاج، أصلح على فرع أو تراجع إلى آخر إصدار مثبت قبل المرحلة التالية.

الإصلاحات في المرحلة07 فقط لما كشفه التحقق. لا تضف مدفوعات أوAuth أوERP أوذاكرة لمجرد أنها ضمن الرؤية المؤسسية المستقبلية. لها مسار مستقل وتفويض بيانات وبوابات أمن.

## بروتوكول كشف الانحراف

إذا لم تجد مسارًا أو API في المصدر فدوّن `UNVERIFIED` وافحصه. إذا اختلفت وثيقة تاريخية مع الكود/الإنتاج، احفظ الفرق ولا تغيّر الثابت بمجرد نص قديم. إذا تغيرت metadata ولم يتغير المضمون، لا تصفها كصفحة كاملة. إذا نقصت فقرة من DOM فهذه بوابة فاشلة حتى لو بدا الشكل أجمل.

لا تكتب «اكتمل» عند بناء prototype، ولا «تم الربط» عند إضافة شعار نظام. عدّل تقرير المرحلة عند كل نتيجة. لا تعد بنشر المرحلة التالية إلى موعد محدد؛ شرطها إنتاج السابقة والتحقق منه.
