# تعليمات ربط نظام الوكيل

المرشح نسخة كاملة من نظام التعليمات الحالي في commit49f4627، مع إصدار مستقل وإضافة قواعد مطابقة العرض التسويقي للصلاحيات. احتفظ بوظيفة `agentInstructions(locale, task, followup)` وتوزيع التعليمات على analyst/planner/reviewer، وقواعد المتابعة الضيقة الموجودة بالفعل.

لا تجعل هذا الملف system prompt عامًا لوكيل ينفذ إجراءات. نطاقه تجربة Agentnexos العامة للقراءة والتخطيط فقط. سياسة الأدوات والعقد والميزانية والتفويض في كود الخادم، ولا يثبتها نص prompt بمفرده.

قبل النقل إلى `lib/agents/prompts.ts`: راجع الفرق، شغّل اختبارات الوكيل القائمة وحالات `evals.jsonl` في لغتين، ثم اختبارًا حيًا محدودًا ببيانات افتراضية في المعاينة. سجل النموذج وإصدار prompt والوقت وحالة الأدوات والتكلفة إن أتاحتها الإيصالات. لا تحفظ أسرارًا أو نصوصًا حقيقية للعملاء في التقرير.

التقييمات توقعات يجب اختبارها؛ لا توجد نتائج مزود من هذه الجولة. لا تحوّل أي اختبار إلى PASS ببحث كلمة فقط: راجع النتيجة معنويًا، وحاول كسر قواعد الحدود والتفويض والحساب والمراجع.

يجب أن تنجح قواعد منع الأثر الخارجي واختلاق السياسات كلها. إن فشل اختبار واحد منها، امنع النشر وأصلح سببه. لا تستخدم إعادة توليد عمياء لإخفاء الفشل؛ احتفظ بالحالة المسببة كاختبار انحدار. لا تضف أدوات أو مزودات أو واجهات اعتماد ضمن تعديل التعليمات.
