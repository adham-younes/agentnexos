## 4. دعم البحث اللحظي (مصادر موثّقة)

### 4.1 تشغيل الوكيل غير المتزامن على Vercel

- **Vercel Workflows** صار GA: «أسهل طريقة لكتابة وكلاء طويلي التشغيل ومتينين
  وقابلين للملاحظة»؛ تجاوز 100 مليون تشغيل و500 مليون خطوة على 1500 عميل.
  يدعم وكلاء لا نهائيي التشغيل مع حالة وأدوات واستئناف عند أحداث خارجية.
  <https://vercel.com/blog/a-new-programming-model-for-durable-execution>
- **AI SDK v7 + `WorkflowAgent`**: التتبّع الحتمي خطوة-خطوة، إعادة المحاولة
  التلقائية، والموافقة البشرية عبر `needsApproval: true` **تُعلّق** سير العمل
  المتين حتى يستجيب المستخدم — ده بالظبط «بوابة الموافقة».
  <https://vercel.com/kb/guide/ai-gateway-and-ai-sdk>
- **Fluid Compute**: سقف تنفيذ يصل 15 دقيقة، ومهام `waitUntil` بعد الرد، وتجميد
  الفاتورة أثناء انتظار الـI/O (خفض حتى 85%).
  <https://www.digitalapplied.com/blog/vercel-fluid-compute-eliminating-cold-starts-90-cost-cut>
- **حدود الـHobby**: **مهمتان cron فقط** لكل حساب — قيد تصميمي لازم يُحسب.
  <https://vercel.com/changelog/vercel-cron-jobs-are-now-generally-available>
- **بديل متين**: Inngest — كل خطوة طلب HTTP مستقل، فالعمل يمتد دقائق/ساعات بلا
  تجاوز أي مهلة. <https://www.inngest.com/blog/vercel-long-running-background-functions>

### 4.2 حقيقة معمارية يجب تصميم كل شيء حولها

> تحليل 1600+ تتبّع (NeurIPS 2025) على 7 أطر: **36.9% من حالات الفشل في الإنتاج
> سببها سوء نقل السياق بين الوكلاء، لا جودة النموذج.** الأنظمة متعددة الوكلاء
> تستهلك **~15 ضعف** توكينات chatbots عادية.
> <https://vercel.com/i/multi-agent-systems>

**القرار المعماري:** لا نبني «مُنسّق متعدد الوكلاء» كمظهر تسويقي. نبني **وكيلًا
واحدًا بمعالجات أدوات حتمية**، ونضيف تعدد الوكلاء فقط عند تحقّق أحد ثلاث بوابات:
كتالوج أدوات > 15، أو مهام متوازية، أو فيض سياق بعد الضغط. ده يطابق `GUARDRAILS §6`
(لا ادّعاء غير منفَّذ).

### 4.3 المنافسون في MENA

- فئة المنصات العربية للوكلاء: **Orki · Arabot · DXwand · Thinkstack** — تركيز على
  قنوات المحادثة (واتساب/إنستجرام) والمبيعات. <https://orki.ai/en/blog/the-top-5-customer-engagement-platforms-in-2025>
- السوق الأوسع: **Sana/Workday · Copilot Studio · Vertex AI Agent Builder ·
  watsonx Orchestrate · Agentforce · UiPath · CrewAI**؛ معيار التقييم: الحكامة
  والتتبّع والتكاملات والامتثال. <https://sanalabs.com/agents-blog/leading-ai-enterprise-fortune-500>
- **فرجتنا:** ندرة منصات تركّز على **أتمتة المستندات العربية** (لا المحادثة)، مع
  **دليل تتبّع ظاهر** و**أمانة الادّعاء**. ده تقاطع الكفاءة الحالية مع الطلب.

## 5. إمكانية الاستمرار غير المتزامن — التقييم الحقيقي

### 5.1 أوضاع التشغيل المتاحة

| الوضع | متاح؟ | ملاحظة |
|---|---|---|
| جلسة واحدة متزامنة (أنا شغّال دلوقتي) | ✅ | تستمر ما دامت الجلسة مفتوحة |
| تنفيذ خلفي داخل الجلسة (build/test/screenshot) | ✅ | عبر `setsid nohup` — مُجرَّب أعلاه |
| نشر تلقائي عند الدفع | ✅ بعد إصلاح الهوية | مثبَّت |
| نشر مباشر عبر واجهة Vercel | ❌ | يحتاج توكن جديد منك |
| تشغيل جلسات إضافية بالتوازي | ✅ | عبر OpenHands API key |
| مهمة مجدولة تفتح جلسة دوريًا | ⚠️ مع كود العمل وحده | مهمة واحدة متاحة على Hobby |

### 5.2 «لو نمت، هل تكمل؟» — بصدق

| السيناريو | الجواب |
|---|---|
| الجلسة دي مفتوحة وأنت نايم | **آه، أكمّل** — بس تنفيذ **تسلسلي داخل الجلسة**، مش متزامن بالتوازي المتعدد |
| تبغى «أنا مش موجود خالص» مع استمرار ساعات | **مش مضمون** — الجلسة ليها عمر إداري |
| تبغى استمرارًا حقيقيًا متعدد الوكلاء بالتوازي | **ممكن** — عبر OpenHands API لفتح جلسات متخصصة (تصميم/محتوى/وكيل) |
| تبغى تكملة تلقائية على السحابة أسبوعًا | **محتاج** مفتاح OpenHands API مسجّل + مهمة مجدولة (راجع 6) |

**الخلاصة:** الجلسة الواحدة كافية للمرحلة 3 كاملة (محتوى — بلا نشر إنتاجي).
المراحل 4-6 تحتاج **توكن Vercel**، وكل الاستمرارية اللاحقة تحتاج **مفتاح OpenHands
API** (اللي شغّالين بيه دلوقتي).

## 8. قواعد ملزمة (من `GUARDRAILS` — لا تُنقض)

1. لا دفع مباشر إلى `main`؛ كل مرحلة على فرعها.
2. `pnpm build` أخضر شرط لكل دفعة.
3. لا أسرار في المستودع.
4. لا تغيير بصري غير موثَّق بلقطة قبل/بعد.
5. لا اختراع أرقام/عملاء/شهادات/تكاملات.
6. لا ادّعاء قدرة غير منفَّذة — «متاح الآن» أو «خارطة الطريق».
